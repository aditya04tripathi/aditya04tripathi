## Key Conventions

### Coding Style
- No semicolons (Prettier `semi: false`)
- Double quotes (Prettier `singleQuote: false`)
- Trailing commas ES5 style
- 80 character print width
- LF line endings
- Tailwind class sorting via `prettier-plugin-tailwindcss` (functions: `cn`, `cva`)

### Component Patterns
- shadcn/ui v4 components use `@base-ui/react` primitives (not Radix UI)
- Variants via `class-variance-authority` (`cva`)
- Class merging via the `cn` package (re-exported from `@/lib/utils`)
- Components receive `data-slot` attributes for compound component identification
- UI components live in `components/ui/`, app components in `components/`

### Theming
- `next-themes` with `attribute="class"`, `defaultTheme="system"`, `enableSystem`
- `disableTransitionOnChange` is enabled
- Design tokens use oklch color space throughout
- Neutral base color palette (achromatic, no hue)
- Press "d" to toggle dark mode (only outside form/editable elements)

### Next.js
- App Router only (no `pages/` directory)
- RSC enabled by default (components are Server Components unless marked `"use client"`)
- Next.js 16 has breaking changes from training data — always consult `node_modules/next/dist/docs/` before using unfamiliar APIs
- Fonts: Geist (sans, `--font-sans`) and Geist_Mono (mono, `--font-mono`) via `next/font/google`
